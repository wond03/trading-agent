# 🌙 暗夜猎手 NightHunter

> 森林查尔斯 SMC 价格行为课程的规则实现 —— 云端自动盯盘 + **WEEX 模拟盘**的**信号提示引擎**

本引擎跑在 GitHub 私有仓库 `wond03/trading-agent` 的 **GitHub Actions**（工作流 `watch.yml`，执行 `engine/main.py`）上，**当前只看 15m** 一个周期（1H 已撤掉），方向、背景、入场全部在 15m 上判定。信号口径为 **`SIGNAL_MODE="fvg_both"`**：对每一个**仍未回填、且没有被后生成的反向缺口接管（区间重叠）**的 15m 缺口，当价格**首次探进**它时，按**该缺口自己的方向**提示（看涨缺口 → 做多、看跌缺口 → 做空），多、空两侧**各自独立**。再叠加**三道过滤**（① 长影线拒绝 ② 影线回踩 ③ 可靠结构止损位），三者全满足才提示。行情取自 **WEEX 合约 V3** 接口（降级备用 Gate 现货），交易通道是 **WEEX 模拟盘**。目前 **`DRY_RUN=1`：只推信号 + 标注图、不下任何单**，下单决策权完全在你手里。

## 现行参数（2026-10-07）

| 参数 | 值 |
|---|---|
| 品种 | **BTC / XAU（黄金）** |
| 周期 | **只看 15m**（`BASE_TF=HTF="15m"`；1H 已撤掉） |
| 结构 swing | **3**（四处一致） |
| 信号模式 `SIGNAL_MODE` | **`"fvg_both"`**（两侧独立；方向 = 缺口自身方向） |
| 过滤 ① `FVGB_REJECT_LONG_WICK` | **True**（影线 ≥ max(实体×1.5, 价格×0.08%)） |
| 过滤 ② `FVGB_WICK_ONLY` | **True**（必须影线探进缺口；实体压进 = 不做） |
| 过滤 ③ `STOP_MODE` | **`"key"`**（止损 = 本段结构极值，距离 0.2%~0.65%） |
| 止盈 `TP_MODE` / `TP_PCT` | **`"pct"` / 1.0**（入场价 ±1%，与杠杆无关） |
| 仓位 | 保证金 **5 USDT/单** × 杠杆 **50x** ≈ 名义 **250U** |
| 推送时段 | 北京 **05:00–07:00 静默**（`QUIET_HOURS_BJ=(5, 7)`） |
| 运行模式 | **`DRY_RUN=1`**（只提示、不下单） |

## 关键设计

1. **只用课程体系**：结构 / 流动性 / FVG —— **不引入任何传统指标**（均线、MACD、布林带等）
2. **只提示、不下单**：`DRY_RUN=1` 下引擎**只推信号 + 标注图**，不触碰账户持仓与挂单（对账 / 持仓管理 / 撤挂单整段跳过）；要恢复自动模拟盘下单，把 `DRY_RUN` 改回 `"0"`（**只改这一处**）
3. **状态持久化**：`engine/state.json` 每轮 git commit；**严禁**为它配置 `actions/cache`（会复活陈旧的持仓状态）
4. **无未来函数**：实盘入口剔除未收盘 K 线；swing/BOS 判定带 `SMC_STRICT_CAUSAL` 守卫
